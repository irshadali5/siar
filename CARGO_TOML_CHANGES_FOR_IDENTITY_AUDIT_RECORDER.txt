Root Cargo.toml changes needed for `siar-identity-audit-recorder`
==================================================================

This is a brand-new crate, so it needs two additions to your root
`Cargo.toml`:

1. In `[workspace] members = [...]`, add (placed next to
   `siar-identity-multidevice`):

    "crates/siar-identity-audit-recorder",

2. In `[workspace.dependencies]`, add:

    siar-identity-audit-recorder = { path = "crates/siar-identity-audit-recorder" }

Note on `workspace-hack`:
This workspace uses `cargo-hakari` via the `workspace-hack` crate.
`crates/siar-identity-audit-recorder/Cargo.toml` includes:

    workspace-hack = { version = "0.1", path = "../../workspace-hack" }

After these additions are in place:
- `cargo check -p siar-identity-audit-recorder`
- `cargo test -p siar-identity-audit-recorder`
- `cargo clippy -p siar-identity-audit-recorder -- -D warnings`
- `cargo hakari verify`

all succeed cleanly.
