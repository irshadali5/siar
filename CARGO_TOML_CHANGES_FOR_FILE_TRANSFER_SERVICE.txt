Root Cargo.toml changes needed for `siar-file-transfer-service`
==================================================================

This is a brand-new crate, so it needs two additions to your root
`Cargo.toml`:

1. In `[workspace] members = [...]`, add (placed next to
   `siar-blob-manifest`):

    "crates/siar-file-transfer-service",

2. In `[workspace.dependencies]`, add:

    siar-file-transfer-service = { path = "crates/siar-file-transfer-service" }

After these additions are in place:
- `cargo build -p siar-file-transfer-service`
- `cargo test -p siar-file-transfer-service`
- `cargo clippy -p siar-file-transfer-service -- -D warnings`

all succeed cleanly.
